# Anwar's Portfolio

- A personal homepage (`index.html`) with links to projects and contact information.
- A thank-you page (`thankyou.html`).
- Project images and assets in the `assets/` folder (screenshots, resume, and photos).

## Projects and assets

The `assets/` folder currently contains:

- `Anwar_Resume (2).pdf` — my resume (PDF)

## Technologies

- Static assets (images and PDF) served from the `assets/` folder.
